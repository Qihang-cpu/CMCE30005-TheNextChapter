# AI Use Declaration

CMCE30005 Interim Project Report | TheNextChapter Group 2 | September 2026

We used OpenAI ChatGPT, including the Codex interface, and Anthropic Claude Code during this project. ChatGPT supported brainstorming, research-question development, analysis-plan review, interpretation of published project results, drafting and revision of the report, English editing and document formatting. Claude Code supported the development and revision of analysis code and the data-analysis workflow. AI-assisted wording is retained in the report, and AI assistance was used in developing project code.

Examples include revising the original rental-arbitrage question to match the supplied Airbnb snapshot, reviewing host-grouped validation and the segment-rate baseline, and simplifying explanations of review activity and model performance. These tools did not supply the numerical observations. Reported results come from the project's analysis of the supplied dataset.

On 16 September, ChatGPT/Codex also assisted with correcting the pooled fold-prevalence comparator in scripts/11_segment_rate_baseline.py. Its AUC and average precision were recalculated from published validation-fold counts. The segment-rate baseline and forest results were unchanged.

The accompanying report cites this declaration as acknowledgement of retained AI-assisted wording. The references below identify the tools and project-specific outputs. Code authors should provide the required attribution beside retained AI-generated or adapted code. The group remains responsible for the submitted analysis, writing and references.
